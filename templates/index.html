How to connect

Drag from any small dot on a block to a dot on another block, in any direction (top, bottom, left or right). Dropping on the block itself also works.

Click an arrow to select it, then press Delete (or click the red X) to remove it. Select an arrow to change where it leaves and enters.

Loops: bottom dot = Body, left dot = Exit. Connect the last block of the body to the dot on the right side of the loop.

      Writing guide 
      START
INPUT n : int "Enter a number"   types: int, float, text, list, floatlist
INPUT a, b, c : int "Three numbers"   fixed number of values on one line (space, comma or / between)
INPUT nums : list "Many numbers"   any number of values, kept in a list
SET total = total + n            (also:  total <- total + n)
PRINT "Sum is", total
IF n mod 2 = 0 THEN
    ...
ELSE
    ...
END IF                           (ELSE IF is allowed)
WHILE n > 0 DO
    ...
END WHILE
FOR i FROM 1 TO n STEP 1 DO
    ...
END FOR
END

// a comment line above a step is that block's note (it becomes a # comment in the code).
// Put formulas inside a note between $ signs:   // Roots: $x = (-b + sqrt(b^2 - 4*a*c)) / (2*a)$

mod = remainder, div = whole-number division,
= in a condition means "is equal to", ^ means power.
Functions: sqrt, abs, floor, ceil, sin, cos, log, min, max, len ...
